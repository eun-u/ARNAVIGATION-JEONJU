- 공식 출처: <https://www.data.go.kr/data/15028201/standard.do>
- 데이터 ID: `15028201`
- 이번 반입 범위: 공식 페이지 스냅샷, 제공된 50,000행 CSV, 28개 컬럼 명세
- 실제 행 데이터: `data/raw/national/crosswalks/2026/전국횡단보도표준데이터_50000건.csv`

- 전주시 행: 0건
- 상태: `verified=false`, `graph_update_allowed=false`

공공데이터포털은 그리드 다운로드를 최대 5만 건으로 제한하며 전체 데이터에는 API 사용을 안내한다. 제공 파일에는 군산시·진안군·무주군 등 전북 자료가 있지만 전주시 행은 없으므로 전주 Graph에 병합하지 않았다. 추후 전체 API 결과나 전주시 원본이 제공되면 좌표·관리번호·기준일자를 검증한 뒤 후보 데이터로 연결한다.

`보도턱낮춤여부`, `점자블록유무` 등 접근성 컬럼의 공란은 `없음`이 아니라 `unknown`으로 유지한다.

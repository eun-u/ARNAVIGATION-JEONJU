# 전국횡단보도표준데이터 컬럼 참조

- 공식 출처: <https://www.data.go.kr/data/15028201/standard.do>
- 데이터 ID: `15028201`
- 이번 반입 범위: 공식 페이지 스냅샷과 26개 컬럼 명세
- 실제 행 데이터: 포함하지 않음
- 상태: `verified=false`, `graph_update_allowed=false`

공공데이터포털은 그리드 다운로드를 최대 5만 건으로 제한하며 전체 데이터에는 API 사용을 안내한다. 전주 백엔드 데이터가 제공되면 `시도명`과 `시군구명`으로 전주시 행을 선별하고, 좌표·관리번호·기준일자를 검증한 뒤 별도 원본 디렉터리에 보관한다.

`보도턱낮춤여부`, `점자블록유무` 등 접근성 컬럼의 공란은 `없음`이 아니라 `unknown`으로 유지한다.

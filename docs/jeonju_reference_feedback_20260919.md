# 기준점 등록 피드백 수정 — 2026-09-19

사용자가 현장에서 기준점 A 버튼을 눌러도 반응이 없다고 보고했다. 확인 당시 ADB에는 에뮬레이터만 연결돼 있어 해당 휴대폰의 입력값·AR 상태와 실제 실패 원인은 재현하지 못했다. 코드에서는 등록 결과와 입력 오류를 화면 맨 위에만 표시하고, AR 등록 callback이 오지 않을 때 대기 종료 안내가 없는 문제를 확인했다.

- 이름·위도·경도·위치 오차를 숫자 변환 전에 검사하고 누락된 값을 한국어로 안내한다. 기존 정합 범위와 위치 오차 요건은 유지한다.
- 기록 중 상태와 성공·실패 메시지를 A/B 버튼 바로 아래에 표시한다. A/B 등록 상태와 시연 시작의 미충족 조건도 표시한다.
- AR callback을 최대 5초 기다리고 응답이 없으면 정합을 초기화해 다시 기록하도록 안내한다. 화면 중단·추적 손실 후 늦게 도착한 callback은 취소된 요청을 복구하지 않는다.
- 정합이 바뀌면 현장 확인 체크를 초기화한다.

검증: `:app:testDebugUnitTest` 40개 통과(추가 회귀 7개 포함), `:app:lintDebug` 오류 0/경고 30, `:app:assembleBenchmark` 성공. 입력 누락·비정상 숫자, A 기록의 정상 null 결과, callback timeout·오류·화면 취소를 검사했다. 실제 ARCore 기준점 등록과 화면 동작은 휴대폰 재연결 후 확인해야 한다.

# 전주 실시간 콘 감지 구현 상태 — 2026-09-19

후속 구현: [고정 코스 PoC 및 시연 안내](jeonju_fixed_course_delivery_20260919.md). 아래는 초기 콘 검출 구현 시점의 기록이다.

사용자 선택은 추가 촬영 없이 기존 5개 촬영 자료를 활용하여 휴대폰 카메라로 실시간 콘 감지와 우회를 시연하는 것이다. 현재 구현은 콘 검출과 기존 공간 판단 연결까지이며, 현장 자동 우회 완료를 검증한 상태는 아니다.

## 구현

- `ConeShapeDetector`는 주황색, 위아래 주황 영역으로 둘러싸인 밝은 띠, 아래로 넓어지는 형태를 함께 검사한다. 입력은 현재 프레임의 실제 픽셀이며, 출력은 `traffic_cone` 이미지 박스와 규칙 품질 점수다. 별도로 학습한 신경망이나 보정된 확률이 아니다.
- 기존 EfficientDet와 같은 회전 보정 이미지에서 실행한다. 파이프라인 버전은 `efficientdet-lite0-int8/1+cone-hsv-shape/1`이며 기존 가중치 SHA는 그대로다. 모델 매니페스트, 실행 이벤트, 새 수집 파일에 규칙 검출기 정보를 기록한다.
- 수집 대기 화면에 `실시간 콘 감지·우회` 진입 버튼을 추가했다. Live 준비 화면에서도 카메라 콘 박스와 개수가 표시된다. 이 미리보기는 경로 변경을 발생시키지 않는다.
- 안내 시작 후 콘 관측은 기존 깊이, 보도 마스크, 2초 정지 관측, 위치 정합, 경로 매칭 검사를 거친다. 경로 선택은 AI 검출기가 하지 않는다.
- 기존 경로 중심선 정책은 시연용 개입 기준이다. 실제 통행 폭이나 휠체어 통과 가능성을 측정한 결과로 해석하면 안 된다. 공동 Graph와 검증 상태는 수정하지 않았다.

## 확인 결과

실제 5개 자료의 CPU 이미지 2,946장을 원래 회전값으로 보정하고, 앱과 동일한 Kotlin 검출기에 입력했다. 129개 프레임에서 총 143개 콘 후보 박스가 나왔다. 이는 검출 건수이며 정확도나 재현율이 아니다. 개발에 사용한 같은 자료의 재검사이므로 독립적인 현장 성능 평가도 아니다. 야간 콘 장면의 박스가 실제 콘에 놓이는 것을 표본 이미지로 확인했으며, 흐림·작은 물체·가려짐에 따른 누락 가능성이 있다.

감사 입력과 출력은 `data/ai-evaluation/runs/jeonju-cone-20260919/frames.tsv`, `cone_predictions.tsv`에 있다. `*-cones-current-*.jpg`는 현재 조건으로 다시 생성한 검토 이미지다. 이전 `*-cones-*.jpg`와 결과를 혼동하지 않는다. 원본 ZIP, 센서 기록, 정합 상태를 수정하지 않았다.

앱 단위 테스트 40개, AI 모듈 19개(실제 픽셀 감사 1개 포함), Fusion 12개가 통과했다. 합성 콘/비콘 판별과 콘의 깊이·정합·보도 조건 회귀 검사를 포함한다. Benchmark APK 빌드와 Debug lint도 통과했다. 이 결과는 실제 S23 현장 우회 성공을 의미하지 않는다.

## 남아 있는 제한

5개 촬영본 모두 `calibration_status=pending`, `replay_eligible=false`다. 기록 GPS의 최선 보고 정확도도 약 3.79m로, 현재 두 기준점 정합의 0.5m 기준을 충족하지 않는다. 이 값을 임의로 낮추거나 정합 완료로 바꾸지 않았다. 따라서 기존 녹화로 콘 검출을 검증할 수 있지만, 이를 곧바로 정합된 Live/Replay 우회 실증으로 인정할 수 없다.

촬영된 우회 장면은 영상 자료다. 이를 현재 위치에 대응하는 경로로 쓰려면 위치와 지도 구간의 대응을 별도로 해결해야 한다. 이 변경에서 영상 기반 위치 추정이나 우회 영상의 자동 지도 등록을 구현한 것은 아니다. 현재 Live 안내 시작에는 여전히 유효한 기준점 정합과 센서 상태가 필요하다.

빌드 후 연결 목록에는 `emulator-5554`만 있으며 S23 `R3CWA0J3XRZ`는 없었다. 새 APK를 S23에 설치하거나 현장 실행하지 않았다. APK는 `android/app/build/outputs/apk/benchmark/app-benchmark.apk`다.
